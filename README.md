# Офис BOSS — PWA

Статическая папка, публикуется как есть на любой HTTPS-хостинг (без сборки).

- `index.html` — офис (оба вида: горизонтальный / вертикальный для Z Fold 7), всё встроено, работает офлайн.
- `state.json` — живое состояние ботов. Читается при открытии, при возврате в приложение и каждые 60 с.
  Новое состояние применяется, когда меняется `updatedAt` (на стыке циклов анимации, без рывков).
- `sw.js` — кеширует оболочку; `state.json` всегда из сети (network-first, cache: 'no-store'), кеш — только офлайн.
- Индикатор в правом верхнем углу: зелёный — состояние из state.json, жёлтый — встроенное (нет сети).

## Формат state.json
{ "updatedAt": "ISO-время", "meeting": true | false | "auto",
  "bots": { "<Имя бота>": { "state": "...", "talking_with": "<Имя>", "insight": true, "carry": "env|folder", "visits": ["<Имя>"], "note": "..." } } }

state: boss | busy | reporting_to_boss | talking_with | reading_book | meeting
meeting: true — общее совещание в Конференц-зале; иначе (false / "auto") совещания нет, свободные боты сидят в Книжном клубе.
Имена: BOSS, Совет директоров, Сделки, Портфель, Дентал Центр, Жалобы ДЦ, Новая стоматология,
Обучение партнёров, Эксперименты, Инстаграм, Кофе Про, Здоровье, Путешествия, Развитие.

## Установка на Galaxy Z Fold 7
Открыть адрес сайта в Chrome → ⋮ → «Добавить на гл. экран» → «Установить». В Samsung Internet: ☰ → «Добавить страницу на» → «Главный экран».
